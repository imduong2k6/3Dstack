# Skill feedback

The pipeline's tuning loop: write the lesson after every project.

| File | Written by | Contents |
| --- | --- | --- |
| `<skill>.md` | Supervisor, Modeler, workers | One line per lesson: what went wrong, the rule that would have prevented it, project and asset |
| `ideas.md` | Researchers | Workflow findings rated `later` |
| `projects.md` | `retro` | One line per project: rounds, time and credits per stage |
| `CHANGELOG.md` | Manager | Every skill change, with the evidence and your approval |

A lesson that shows up on two projects becomes a rule in the skill, after you approve it.
